# html框架结构
a file for Microsoft visual studio 2022 to init html(代码补全功能文件）


## how to use 
  1 先下载文件
   
  2 打开 Microsoft visual studio 2022  
  
  3 选择工具选项卡 其中的代码片段管理器 选中文件后导入

  4 在新的html文件中输入“inithtml”后按Tab键自动补全框架











## 框架内容
```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title></title>
</head>
<body>

</body>
</html>
```
